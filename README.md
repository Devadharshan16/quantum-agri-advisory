# Quantum Intelligence-Based Agricultural Advisory System

**Course:** 23CSE463 Quantum Computing — Amrita School of Computing, Chennai  
**Architecture:** QSVC (Quantum Support Vector Classifier) with ZZFeatureMap fidelity kernel

---

## Quick Start

```powershell
# 1. Install dependencies
pip install -r requirements.txt

# 2. Prepare data (all 2200 samples, 80/20 split)
python data_prep.py

# 3. Run unit tests for the quantum kernel module
python -m pytest test_qkernel.py -v

# 4. Train QSVC with nested cross-validation (~5-15 min depending on grid)
python trainv2.py --verbose

# 5. Train & evaluate classical baselines for comparison
python baselines.py --verbose

# 6. Generate error analysis, confusion matrices, bootstrap CI, multi-seed stability
python analysis.py --verbose

# 7. Generate learning curves and gamma-concentration plots
python learning_curve.py --verbose

# 8. (Optional) Noise robustness study — takes longer
python noise_study.py --verbose

# 9. Interactive prediction
python predict.py --interactive
```

## Discussion Notes (for report)

1. **Kernel concentration and bandwidth:** At small gamma (≤0.1), the quantum kernel entries are close to 1 (near-identity), making the kernel weakly discriminative but stable. At large gamma (≥0.5), off-diagonal entries collapse toward 0 (kernel concentration), and the SVM sees each point as isolated — accuracy drops sharply. The optimal gamma is a narrow sweet spot.

2. **Parity with classical performance:** The tuned QSVC achieves accuracy competitive with (but likely not exceeding) a well-tuned RBF-SVM. This is expected: on a clean, 7-feature, noiseless-simulation dataset, classical models have no disadvantage. We do not claim quantum advantage.

3. **Small-gamma behavior:** At very small gamma, the ZZFeatureMap kernel approximates a linear kernel (features barely perturb the quantum state). The quantum advantage, if any, comes from the non-linear ZZ interaction terms at moderate gamma — but this must be validated on harder datasets.

4. **Noiseless simulation caveat:** All main results use exact statevector simulation. Real quantum hardware would introduce gate errors, readout noise, and decoherence. The noise study shows that accuracy degrades gracefully with finite shots but drops significantly under depolarizing noise > 1%.

5. **Dataset limitations:** The crop recommendation dataset is clean, well-balanced (100 samples per class), and essentially synthetic-like. Classical models solve it near-perfectly. This is a proof-of-concept for the quantum pipeline, not a demonstration of quantum advantage.

6. **Swap Test connection (Class 43):** The fidelity kernel K(x,x') = |⟨φ(x)|φ(x')⟩|² is mathematically identical to the Swap Test outcome probability. Our pipeline applies this syllabus concept directly to ML.

7. **No barren plateaus:** Unlike VQC (which suffered from vanishing gradients with 22 classes), QSVC has zero trainable quantum parameters. The kernel is fixed; only the classical SVM is optimized (convex problem).

8. **Future work:** (a) Run on IBM quantum hardware via Qiskit Runtime. (b) Explore trainable quantum kernels (kernel alignment training). (c) Test on larger, noisier agricultural datasets. (d) Investigate PauliFeatureMap variants for richer feature interactions.
